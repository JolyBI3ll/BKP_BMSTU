## Установка и запуск

### 1. Клонирование репозитория
```bash
  git clone git@gitlab.bmstu.ru:iu5/diplom_balashov/edit-attachment-in-drawio.git
  cd edit-attachment-in-drawio
```

### 2. Сборка Frontend
```bash
  cd taiga-contrib-drawio/front
  npm install
  npm install -g gulp-cli
  gulp build
```

### 3. Запуск docker
```bash
  cd ../..
  docker compose build
  docker compose up -d
```

### 4. Доступ к системе
- Frontend: http://localhost:9000
